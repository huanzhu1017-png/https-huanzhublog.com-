My FP&A Agent Team

Seven AI agents, a team lead and a PMO run the forecast, budget and month-end cycles. Each agent owns one tool on this site; together they close the loop from collecting data to sending the message.

What this shows: the operating system I designed for a brokerage FP&A team: who does what, who checks whom, and where a human signs off. The tools are static demos with made-up data; click any agent to see what it owns.

Click a box to see what the agent takes in, produces and hands off. Solid arrows pass work on; the dashed arrow sends work back when it doesn't tie out.

Rules every agent follows

A person always signs offAgents only write drafts. Every email is reviewed before it is sent.
Nothing moves until it ties outThe Controller checks every number against its source. Small gaps are allowed in the first cycles; after that, everything must tie.
Every issue is written downAccounting questions go into one log with an owner and a status, so the record outlives any single cycle.
