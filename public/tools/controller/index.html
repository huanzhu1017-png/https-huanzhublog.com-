Controller: Tie-out and Issue Log

Demo

Every number an agent produces is checked against its source before it moves on. Anything that does not tie goes back, and every accounting question is logged.

What this shows: the control point in the agent team: tie-outs with a tolerance that tightens each cycle, a hold that sends work back, an issue log that outlives any single cycle, and the month-end calendar. All names and figures are made up.

Tie-out: does each agent's number match its source?

Small gaps are allowed in the first cycles while sources settle; after that, everything must tie. A hold sends the work back to the agent. $K.

Accounting issue log

Every accounting question found during checks, with an owner and a status. The log is the long-term record; a weekly summary goes to Accounting.
